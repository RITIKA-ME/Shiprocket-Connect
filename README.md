# Shiprocket Connect — C2C International Shipping

> **Making international shipping simple for everyday consumers.**

### The Problem

Shiprocket's existing international shipping experience was built primarily for high-volume sellers. For individuals sending occasional parcels abroad, the process involved multiple steps, documentation, KYC and product classification.

### The Solution

Built **Shiprocket Connect**, a consumer-first C2C shipping app enabling users to send personal parcels to **200+ countries** through a simplified flow:

**OTP → Pickup → Destination → Product → Package → KYC → Payment → Pickup**

### My Role

* Defined product flows, requirements and user journeys
* Designed the experience using **Claude**
* Worked with design, engineering and business teams
* Conducted UAT and drove product improvements
* Used **AI/OCR for KYC document validation**
* Analysed the funnel using **GA4 & Firebase**
* Experimented with QR-led GTM and iterated based on user response

### Key Product Insight

The goal wasn't to remove the complexity of international shipping, but to **hide unnecessary complexity from the consumer while maintaining compliance.**
